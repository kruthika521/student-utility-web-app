🎓 Smart Student Utility

Key Features

🎓 Grade Calculator

The Grade Calculator helps students calculate total marks, average, and grade instantly. It reduces manual errors and provides quick academic performance evaluation.

🔁 Palindrome Checker

This tool checks whether a word reads the same forward and backward. It helps in understanding string operations and logic building.

🔢 Number Analyzer

Identifies whether a number is even or odd and determines if it is positive, negative, or zero, helping students understand number properties.

🔐 Login Validation

Demonstrates a simple authentication system by validating username and password, useful for learning input validation concepts.

🌙 Dark Mode

Allows users to switch between light and dark themes, improving user experience and demonstrating dynamic styling using JavaScript.
